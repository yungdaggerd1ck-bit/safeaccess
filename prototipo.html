Protótipo

Protótipo do sistema e demonstração 3D

Duas visões do projeto: o circuito que vai rodar o protótipo físico e uma demonstração interativa do portal.

Protótipo do sistema

Simulação do circuito que vai rodar o protótipo físico: ESP32, leitores RFID, servo, LEDs e buzzer. No protótipo físico, esses componentes ficam dentro de uma carcaça.

Se a simulação não aparecer, abra o projeto no Wokwi.

Protótipo portal 3D (demonstração)

Use "Passar pelo portal" para ver a aproximação ao leitor, a leitura do cartão, a checagem dos EPIs e a passagem pela catraca. Arraste a tela para girar o modelo e use a roda do mouse para aproximar.

Como o protótipo funciona

Leitura do cartão

O colaborador aproxima o cartão. O sistema verifica o cadastro e a validade dos treinamentos.

Verificação dos EPIs

Os leitores confirmam os equipamentos exigidos para a área.

Decisão

Com as duas verificações aprovadas, o servo libera a catraca. Caso contrário, o LED vermelho indica o bloqueio.

Registro

Cada tentativa é registrada com data, horário e motivo.
